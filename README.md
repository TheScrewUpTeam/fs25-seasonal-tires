# SeasonalTiresMod

SeasonalTiresMod is a mod for Farming Simulator 2025 that adds dynamic tire management based on seasonal conditions. Switch between all-season, mud, road, and snow tires to optimize your vehicle's performance throughout the year.

## Features
- Dynamic tire switching for different seasons
- Visual tire icons for each type
- Easy-to-use HUD for tire management
- Immersive gameplay with realistic tire effects

## Installation
1. Download the latest release of the mod from the [Releases page](https://github.com/TheScrewUpTeam/fs25-seasonal-tires/releases).
2. Copy the mod archive into your `Documents/My Games/FarmingSimulator2025/mods` directory.
3. Launch the game and enable the mod in gamesave

## Usage
- Access the tire management HUD in workshop to switch between available tire types.
- Sell unused tire sets using separate option in workshop.
- Each tire type is optimized for specific weather and terrain conditions.
- Icons and overlays help you identify the current tire type.
